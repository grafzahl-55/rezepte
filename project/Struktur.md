| Verzeichnis  | Bedeutung                                                                                                                        |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| docs         | Diese Dateien werden in Git Pages veröffentlicht. Dort werden nur die Inhalte abgelegt, die später im Web veröffentliche werden. |
| docs/index   | Hauptseite mit Übersicht                                                                                                         |
| docs/rezepte | Verzeichnis in dem die Texte der Rezepte abgelegt werden                                                                         |
| docs/images  | Verzeichnis für die Rezept-Bilder                                                                                                |
| project      | Notizen zu diesem Projekt                                                                                                        |
| template     | Vorlagen                                                                                                                         |
| rohdaten     | Daten die von mir manuell zum Projekt hinzugefügt werden (Roh-Clippings, PDFs, Bilder)                                           |
| session-logs | Zusammenfassungen, Fazit. (Dateiname: `[YYYY]/[MM]/[YYYY-MM-DD].md`, nur im Wurzelverzeichnis)                                   |
| journal      | Persönliche tägl. Notizen (Dateiname: `[YYYY-MM-DD].md`)                                                                         |
| bin          | Skripte zum Projekt (z. B. `index-check.py`, `index-sort.py`)                                                                    |
| Clippings    | Roh-Clippings/Notizen zu Rezepten, die noch nicht importiert sind (z. B. `Avocado-Wrap mit Dill-Dip.md`)                         |
