# Rezepte

Experiment. Meine Rezeptsammlung als Website auf GitHub???
Wie geht das und ist es das Richtige? 


## Ziel 
Ein KI-Agent (z.B. ClaudeCode) soll hier folgende Aufgaben vornehmen können:

- Aus eine URL zu einem Kochrezept eine Zusammenfassung schreiben.
- Ein Passendes Vorschaubild des Rezepts suchen und hier ablegen
- Vorschaubild in das Rezept einfügen
- Ablage der Dateien gemäß [[Struktur]]
- Update der Indexdatei gemäß [[index-regeln]]
